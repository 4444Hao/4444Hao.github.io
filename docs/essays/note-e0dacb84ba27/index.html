年少不可得之物

回忆选择

摘录 · 来源待核；保留原笔记文字，不据此确认作者或观点。

年少不可得之物，终将困其一生。暮年浮光之景，将之瞬息点醒。又终会因一物一事，而解终生之惑。抬望眼，天上月还似当时月，月下人已非当年心。

无念不是不起念 他而是念起不随 心不随境转 是一种内心极致宁静的状态 我们可以起各种念头 做不到如如不动 不被万物所动 念头升起时能迅速察觉 并且不被其带走 心神不产生执着与挂碍
