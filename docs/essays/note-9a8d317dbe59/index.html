宿命与悖论式命定论

选择行动意义

摘录 · 来源待核；保留原笔记文字，不据此确认作者或观点。

"我不是宿命论，宿命论会导致懒惰。同时我也不相信天道酬勤，它会导致人走向骄傲或者，虚无。当你成功的时候，你会觉得这是你努力拼搏来的，你配拥有这一切，所以你就瞧不起那些失败的人。但当你努力了拼搏了，最后依然失败，还是一无所成，你会陷入一种极大的抱怨，会认为天道不公。我个人更倾向于一种悖论式的命定论。首先人生中的大部分事情是你决定不了了，比如出身，比如机会，比如贵人。但同时，你自己一定要尽力而为。可能百分之九十五的事情是你无法左右的，但依然要在百分之五的空间中，尽百分之百的努力，去撬动那百分之九十五的命定。凡事尽力而为，同时顺其自然，接受命运一切的安排。因为个体太过于渺小。这看似一种悖论，但人生不就是在各种悖论中寻找整合，在各种似是而非中寻求超越吗"
