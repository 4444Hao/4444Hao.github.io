虚无主义

意义情绪

摘录 · 来源待核；保留原笔记文字，不据此确认作者或观点。

虚无主义者以反思的视角揭示了虚无化着的意义，可先认为人需要有一个预设的意义才会对反思到人没有这种意义感到惊讶，一个预设好的凌驾于人超越性上的意义根本无法设想和体验，因为任何反思都能超越任何预设的意义，故这种不被超越的意义逻辑上是不存在的，失去一个不存在的东西并没有真的失去任何东西，只是反思把存在于前反思里的＂预设的意义的必要性＂虚无化了。
如果这个预设的意义指的是社会无形中预设给每个人的结构，那虚无主义就是用宇宙背景为叙事逃避社会叙事，一边依靠社会生活一边却进行将社会溶解在自己身上的自在的结构进行虚无化中获得虚假的自由这失败的谋划，虚无主义者享受的是这失败，享受超越一种叙事走向虚无又被拉回来的超越的过程以体验自己自在的超越性 虚无主义只是一个事实，不是一个思想。它会摧毁人的一切思考，当你真正而彻底地陷入虚无，任何尝试对抗它的方式都显得那么无力，更多的不是你不想做，而是做不到。我们没有必要过度地探讨虚无主义，这带不来任何价值或转机，我们只需要知道虚无是痛苦的，而我们会想要结束这种痛苦。我不知道怎样活着可以结束这种痛苦，但死亡大概率可以。
