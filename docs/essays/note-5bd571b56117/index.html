史铁生谈当下

阅读意义

摘录 · 原笔记署名史铁生，并引用大仲马；归属与原文尚未核实。

史铁生写过这样一段话："我四肢健全时，常抱怨周围环境糟糕，瘫痪后，怀念当初可以行走奔跑的日子。几年后长了褥疮，怀念起前两年安稳坐在轮椅上的时光；后来得了尿毒症，怀念当初长褥疮；又过了一些年，要透析，清醒的时间很少，怀念尿毒症的时候。大仲马也讲过同样的话，他说人生无所谓幸与不幸，只是两种不同境遇的比较罢了。永远记住，活在当下。
