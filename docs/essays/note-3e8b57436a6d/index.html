朋友是阶段性的

关系选择

摘录 · 来源待核；保留原笔记文字，不据此确认作者或观点。

其实朋友都是阶段性的，有一天你会突然意识到，曾经那些无比要好的朋友，那些自己曾深爱过的人，都渐渐的悄无声息的走散了。无论许下过什么誓言，最后都是因为志向、追求、三观不同，殊途末路了。高中要好的慢慢也不再联系了，大学的好朋友一毕业也都回到了自己的家乡，各自奋斗，上班后你跳槽到下一家公司，之前的同事也都只存在于朋友圈。好像真的印证了那句话，数声风笛离亭晚，君向潇湘我向秦。
