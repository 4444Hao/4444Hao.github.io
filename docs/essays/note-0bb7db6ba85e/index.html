劳务市场与精英傲慢

关系意义

摘录 · 原笔记标注：网友评论 @苏徐邳；原始评论链接与语境待核。

网友评论@苏徐邳: 劳务市场，那是大家找工作、靠出卖劳动力换取报酬，以此维持生计的地方。工人们在那儿等待的每分每秒，都是在为自己争取能有收入的机会。他们询问有没有工资或者餐补，这再正常不过了，毕竟时间对他们来说太宝贵了，背后是家庭的柴米油盐，是生活的压力。可你呢，只是一句"电影免费，不支付任何报酬"就打发了，这等于白白占用他们的时间，这不是在利用他们的困境，满足自己助推票房的目的吗？再说观影后的事儿，工人说电影"无聊"，这是他们最真实的感受。每个人的生活阅历、审美偏好都不一样，工人阶级每天在社会底层辛苦打拼，他们有自己看待世界、评价事物的方式。你倒好，直接抱怨他们没看到彩蛋，还说什么"没办法把高审美的东西扩大化"，这不是高高在上的精英式傲慢吗？你有没有想过，在你眼里的"高审美"，对于为生活奔波的工人来说，可能根本就不适用。他们需要的是能映照出自己艰难求职、努力工作，为家庭撑起一片天的生活写照，是那种真切关乎就业、收入与家庭生计，能在心底唤起强烈共鸣的文化体验，而不是被你用所谓的"高审美"标准去评判、贬低。希望你能好好反思一下，尊重一下那些为生活努力奋斗的普通人，别再打着看似好意的旗号，行不尊重他人之事
