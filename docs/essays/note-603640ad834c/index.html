命定之路

选择意义

摘录 · 来源待核；保留原笔记文字，不据此确认作者或观点。

如果你站在童年的位置瞻望未来，
你会说前途未卜，
你会说前途无量。
但要是你站在终点，
看生命的轨迹，
你看到的只有一条路，
你就只能看到一条命定之路。
不知道命运是什么，
才知道什么是命运。
所以很多人口中说着看不到未来，
其实是看到了未来。
人生唯一确定的就是不确定的人生!
所以大胆去做你想做的任何事吧！
活在当下，
抓住周围一切的美好!
